## 🛠️ Technology Stack
This project adheres to a 100% static, client-side, zero-dependency architecture:
- **HTML5:** Semantic markup, accessible component structure, Open Graph & JSON-LD Organization Schema.
- **CSS3:** Custom responsive styling (`css/style.css`) with clean variables, smooth hover transitions, and fluid grid integration.
- **Bootstrap 5.3 (CDN):** Responsive grid layout, mobile collapse navigation, and modern utilities.
- **Bootstrap Icons 1.11.3 (CDN):** Sharp, lightweight vector iconography.
- **Vanilla JavaScript (`js/main.js`):** Sticky navbar scroll effects, mobile hamburger auto-collapse, floating back-to-top interaction, and client-side mailto form dispatch.
- **Zero Server-Side Runtimes:** No Node.js build step required, no database, no PHP, no external API keys required. Works seamlessly when opened directly in any web browser via `file://` or deployed to static hosts.

## 🚀 Deployment Instructions

### Option 1: Open Locally (Immediate Testing)
Simply double-click `index.html` or open any of the `.html` files in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).

### Option 2: Deploy to GitHub Pages (Free & Instant)
1. Initialize a git repository inside the project folder:
   ```bash
   cd C:\Users\Tejas\.gemini\antigravity\scratch\TechCYT-Website
   git init
   git add .
   git commit -m "Initial commit: TechCYT LLP official static website v1.0"
   ```
2. Create a new repository on your GitHub account (e.g. `techcyt-website`).
3. Link and push to GitHub:
   ```bash
   git remote add origin https://github.com/<YOUR-USERNAME>/techcyt-website.git
   git branch -M main
   git push -u origin main
   ```
4. In your GitHub repository settings:
   - Navigate to **Settings** > **Pages**.
   - Under **Build and deployment**, select **Source:** `Deploy from a branch`.
   - Branch: `main` / Folder: `/(root)`.
   - Click **Save**. Your site will be live at `https://<YOUR-USERNAME>.github.io/techcyt-website/`.

### Option 3: Deploy to Vercel (1-Click Static)
1. Install Vercel CLI (or connect via GitHub on [vercel.com](https://vercel.com)):
   ```bash
   npx vercel
   ```
2. Follow the prompt; keep default static settings (no build command needed).
3. Your website is instantly deployed with high-speed CDN and automatic SSL certificate.

### Option 4: Deploy to Netlify
1. Log in to [netlify.com](https://netlify.com).
2. Drag and drop the `TechCYT-Website` folder directly into the Netlify dashboard.
3. Your website will be live in seconds.
